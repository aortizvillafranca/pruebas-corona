# Instrucciones para arrancar la aplicación

Como te he arreglado el código, ahora solo necesitas tener las herramientas básicas instaladas para que funcione. Sigue estos 3 pasos sencillos:

1.  **Instalar el motor**:
    *   Ve a [nodejs.org](https://nodejs.org)
    *   Descarga e instala la versión **LTS** (la recomendada).
    *   Una vez instalado, **reinicia tu ordenador**.

2.  **Preparar la aplicación** (Solo necesitas hacerlo una vez):
    *   Abre una terminal en esta carpeta.
    *   Escribe este comando y pulsa Enter:
        ```bash
        npm install
        ```
    *   Espera a que termine (puede tardar un minuto).

3.  **Arrancar**:
    *   Escribe este comando y pulsa Enter:
        ```bash
        npm run dev
        ```
    *   Se abrirá una dirección web (normalmente `http://localhost:5173`), ábrela en tu navegador.

¡Y listo! Ya deberías ver tu aplicación funcionando.
